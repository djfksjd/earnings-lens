# my_inputs — 내가 직접 넣는 데이터

이 폴더는 **사용자가 직접 작성하는 값**만 둡니다. 자동 수집 데이터(`data/`)와 분리되어 있고,
`README.md`와 `_examples/`를 빼면 **GitHub에 올라가지 않습니다**(`.gitignore`).

| 경로 | 내용 |
|---|---|
| `watchlist.yaml` | 관심 종목 목록 (앱에서 티커를 추가하면 자동 저장) |
| `companies/<티커>/<분기말 연-월>.yaml` | 컨센서스·세그먼트·KPI·가이던스·톤·발언·Q&A·체크포인트 |
| `transcripts/<티커>_<분기말 연-월>.txt` | 직접 붙여넣은 컨콜 원문 |

- 티커 폴더 이름은 `.`을 `_`로 바꿉니다. `005930.KS` → `005930_KS`
- 분기 키는 **분기말 연-월**입니다. 12월 결산 2분기 → `2026-06`, 엔비디아 FY27 2분기(7월 말) → `2026-07`
- 작성 예시: `_examples/companies/EXAMPLE/2026-06.yaml`
- 우선순위: **내 입력 > AI 추출 > 자동 수집**
